# HelioX

GPU-native simulation and training of biophysically detailed neuron networks.

Code for *HelioX: A GPU-Native Framework for Simulation and Training of
Biophysically Detailed Networks* (ICML 2026). The ICML version is tag `icml2026`.

The supplementary material on OpenReview (sha256 `57de4e1ae28bf17e74d58f7f6709b4e9039321ed88b91c44fe5a00858a308b49`)
is an anonymized snapshot of that version: vendored third-party headers and author
initials in code comments were removed, `python_test/` was omitted, and demo scripts
were added.
